# RedGifs Downloader

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/dao088/redgifs-downloader.git
   ```

2. Open Google Chrome and go to `chrome://extensions/`.

3. Enable **Developer mode** in the top-right corner.

4. Click **Load unpacked**.

5. Select the `redgifs-downloader` folder you cloned.

6. Done! The extension is now installed in Chrome.

**Note:** This extension currently supports Google Chrome only.
